These are example resource configurations that a user could define for CipherTrust and Classification integrations, work which was done as a POC in April 2025. This work is not complete as managing the state of the resources and reading the data sources has not been thoroughly tested, however, the provided example run logs show that the correct APIs are indeed being called, with the correct request bodies, for creating the resources in the first place. Given that, it is reasonable to believe that with a little more effort, the integrations could be fully managed/supported with this terraform provider, if desired.
